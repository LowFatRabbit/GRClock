시계 놀이 v2 (iOS 스타일) - 설치와 업데이트

[처음 설치하는 경우]
  1. GitHub 저장소에 이 폴더의 파일을 모두 올립니다. (README.txt는 빼도 됩니다)
  2. Settings > Pages > Branch: main / (root) > Save
  3. 아이폰 Safari로 https://<아이디>.github.io/<저장소이름>/ 열기
  4. 공유 > 홈 화면에 추가
  5. 인터넷이 될 때 홈 화면 아이콘으로 한 번 실행해 두면 이후 오프라인으로 작동합니다.

[이전 버전을 이미 설치한 경우]
  1. GitHub 저장소 > Add file > Upload files 로 이 폴더의 파일을 모두 끌어다 놓고
     Commit changes. (같은 이름 파일은 자동으로 덮어써집니다)
  2. 1~2분 기다립니다.
  3. 아이폰 홈 화면의 기존 '시계 놀이' 아이콘을 길게 눌러 삭제합니다.
     (아이콘 그림과 실행 화면은 '홈 화면에 추가'할 때 고정되기 때문입니다)
  4. Safari로 같은 주소를 열고 공유 > 홈 화면에 추가 > 아이콘으로 한 번 실행.
  * 다시 추가하면 별 개수는 0부터 시작합니다.

[참고]
  - 상단 오른쪽 ··· 버튼: 바깥 분 숫자 보기, 맞히면 시간 읽어 주기, 별 초기화
  - 바늘을 돌릴 때 진동(햅틱)은 iOS 18 이상에서 느껴집니다.
  - 소리는 기기에 한국어 음성이 있어야 납니다.
    (설정 > 손쉬운 사용 > 읽기 및 말하기 > 음성 > 한국어)
  - 이번 버전부터는 인터넷이 될 때 앱을 열면 GitHub에 올린 최신 화면을 자동으로 받아옵니다.
